مدار — راهنمای نصب از صفر (نسخه 0.2.0)
=======================================

فایل‌های این بسته
-----------------
  Code.gs           سرور (شیت، دسترسی‌ها، ورود، آپلود، تقویم و ایمیل‌های خودکار)
  Index.html        خود اپ (یک فایل بزرگ؛ با npm run build:apps-script ساخته می‌شود)
  appsscript.json   تنظیمات اسکریپت (مجوزها، تقویم، درایو)

دو انتشار
---------
  Madar Team    لینک اصلی + API              Execute as: Me  /  Who has access: Anyone
  Madar Google  ورود با گوگل، تقویم و Meet   Execute as: User accessing  /  Anyone with Google account

همه‌ی مراحل را با همان حساب گوگلی انجام بده که شیت را ساخته (حساب مدیر برنامه).


مرحله ۱ — ساخت شیت و فایل‌ها
-----------------------------
 1. یک Google Sheet خالی بساز ← Extensions ← Apps Script.
 2. Code.gs ← Ctrl+A ← Delete ← کل Code.gs را بچسبان.
 3. کنار Files روی + ← HTML ← اسمش را دقیقاً Index بگذار ← کل Index.html را بچسبان.
 4. ⚙️ Project Settings ← تیک Show "appsscript.json" manifest file ← محتوای appsscript.json را بچسبان.
 5. Ctrl+S.
 ✔ چک: در Code.gs با Ctrl+F دنبال MADAR_VERSION بگرد ← باید '0.2.0' باشد.


مرحله ۲ — اجرای setup
---------------------
 فهرست بالای ویرایشگر ← setup ← ▷ Run ← اجازه‌ها را تأیید کن
 (Review permissions ← حسابت ← Advanced ← Go to … ← Allow).
 همه‌ی تب‌ها ساخته می‌شوند و تو مدیر برنامه (سطح super) می‌شوی.
 اختیاری: seedDemo فقط دو نفر را اضافه می‌کند: مدیر برنامه و CPTO.


مرحله ۳ — انتشار «Madar Team»
-----------------------------
 Deploy ← New deployment ← ⚙️ ← Web app
   Description:     Madar Team
   Execute as:      Me
   Who has access:  Anyone
 آدرس Web app را کپی کن (با /exec تمام می‌شود).


مرحله ۴ — ثبت آدرس
------------------
 ⚙️ Project Settings ← Script Properties ← API_URL = آدرس مرحله ۳ ← Save.


مرحله ۵ — انتشار «Madar Google»
-------------------------------
 Deploy ← New deployment ← ⚙️ ← Web app
   Description:     Madar Google
   Execute as:      User accessing the web app
   Who has access:  Anyone with Google account
 آدرس را نگه دار برای مرحله ۷.


مرحله ۶ — چک با diagnose
------------------------
 diagnose ← ▷ Run ← در Execution log باید «نسخه‌ی Code.gs = 0.2.0» و API_URL درست باشد.


مرحله ۷ — تنظیمات داخل مدار
---------------------------
 1. آدرس Madar Team را باز کن و وارد شو.
 2. بک‌آفیس ← تنظیمات: «لینک ورود با گوگل» = آدرس مرحله ۵ ← ذخیره. رمز اولیه‌ی تیم (Madar@1405) را عوض کن.
 3. بک‌آفیس ← افراد: ایمیل گوگل CPTO (جلیل علیزاده) را وارد کن و سطح دسترسی‌اش را «CPTO · همه‌چیز» بگذار.
 4. بک‌آفیس ← سمت‌ها و سازمان: واحدهای دپارتمان (لاین‌ها، مدیران محصول، CRM و عملیات، داده، …)،
    سمت‌ها، تیم‌ها و انواع جلسه را تعریف کن.
 5. اتوماسیون‌های ایمیلی پیش‌فرض خاموش‌اند؛ اگر خواستی روشن کن و یک بار installAutomations را Run کن.


قانون‌های امنیتی
-----------------
 - شیت را با هیچ‌کس به اشتراک نگذار؛ CPTO فقط از لینک اپ وارد می‌شود.
 - سرور فقط داده‌های مجاز هر نفر را برایش می‌فرستد.


به‌روزرسانی‌های بعدی (بدون عوض شدن لینک‌ها)
---------------------------------------------
 Code.gs و Index.html را جایگزین کن ← اگر نسخه گفت، setup را یک بار Run کن ←
 Deploy ← Manage deployments ← Madar Team ← ✏️ ← Version: New version ← Deploy (همین برای Madar Google).
 هیچ‌وقت برای به‌روزرسانی New deployment نزن؛ لینک‌ها عوض می‌شوند.
