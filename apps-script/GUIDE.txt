اطلس ACG — راهنمای نصب از صفر (نسخه 1.12.2)
==============================================

فایل‌های این بسته
-----------------
  Code.gs           سرور (شیت، دسترسی‌ها، ورود، آپلود، ایمیل‌های خودکار)
  Index.html        خود اپ (یک فایل بزرگ، حدود ۱.۵ مگابایت)
  appsscript.json   تنظیمات اسکریپت (مجوزها، تقویم، درایو)

نام انتشارها (جدید)
-------------------
  Atlas Team    لینک اصلی تیم + API        Execute as: Me  /  Who has access: Anyone
  Atlas Google  ورود با گوگل، تقویم و Meet  Execute as: User accessing  /  Anyone with Google account

اگر نسخه‌ی 1.7 تا 1.9 از قبل نصب و کار می‌کند: فقط بخش «به‌روزرسانی» (پایین همین فایل) را انجام بده.
اگر نصب قبلی کار نکرد: از مرحله ۰ شروع کن.

همه‌ی مراحل را با همان حساب گوگلی انجام بده که شیت را ساخته.
داده‌های شیت دست نمی‌خورد؛ فقط کد و انتشارها از نو ساخته می‌شوند.


مرحله ۰ — پاک‌سازی انتشارهای قدیمی
-----------------------------------
 شیت ← Extensions ← Apps Script.
 Deploy ← Manage deployments ← هر انتشار (data، app، هر چیز دیگر) ← Archive ← تأیید.
 در آخر لیست Active باید خالی باشد.
 اگر انتشاری از نوع Library هم ساخته‌ای، آن را هم بایگانی کن.


مرحله ۱ — جایگزینی کامل فایل‌ها
-------------------------------
 1. Code.gs  ← کلیک داخل متن ← Ctrl+A ← Delete ← کل Code.gs جدید را بچسبان.
 2. Index.html ← Ctrl+A ← Delete ← کل Index.html جدید را بچسبان (چند ثانیه صبر کن).
    اگر فایل Index.html نداری: کنار Files روی + ← HTML ← اسمش را دقیقاً Index بگذار.
 3. appsscript.json ← Ctrl+A ← Delete ← محتوای جدید.
    (اگر دیده نمی‌شود: ⚙️ Project Settings ← تیک Show "appsscript.json" manifest file.)
 4. اگر فایل اضافه‌ای مثل Code.gs دوم یا run1 داری، پاکش کن (⋮ ← Delete).
 5. Ctrl+S ← کنار هیچ فایلی نقطه‌ی نارنجیِ «ذخیره‌نشده» نماند.

 ✔ چک: در Code.gs با Ctrl+F دنبال ATLAS_VERSION بگرد ← باید '1.12.2' باشد.
 ✔ چک: در Index.html با Ctrl+F دنبال 1.12.2 بگرد ← باید پیدا شود.


مرحله ۲ — اجرای setup
---------------------
 فهرست بالای ویرایشگر ← setup ← ▷ Run.
 اگر اجازه خواست: Review permissions ← حسابت ← Advanced ← Go to … (unsafe) ← Allow.
 در شیت پیغام می‌دهد: ستون username پر شد و رمز اولیه‌ی تیم Atlas@1405 است.


مرحله ۳ — انتشار «Atlas Team»
-----------------------------
 Deploy ← New deployment ← کنار Select type روی ⚙️ ← Web app   (Library نه!)
   Description:     Atlas Team
   Execute as:      Me (ایمیل خودت)
   Who has access:  Anyone          (نه Anyone with Google account)
 Deploy ← زیر «Web app» آدرس URL را Copy کن (نه Deployment ID).
 ✔ چک: آدرس با https://script.google.com/macros/s/ شروع و با /exec تمام می‌شود.
   اگر /library/ یا /dev داشت، اشتباه است.


مرحله ۴ — ثبت آدرس Atlas Team
-----------------------------
 ⚙️ Project Settings ← پایین صفحه Script Properties ← Edit script properties
   API_URL  =  آدرس مرحله ۳   (اگر هست، مقدار قبلی را کامل پاک کن و جدید را بگذار)
 Save script properties.


مرحله ۵ — انتشار «Atlas Google»
-------------------------------
 Deploy ← New deployment ← ⚙️ ← Web app
   Description:     Atlas Google
   Execute as:      User accessing the web app
   Who has access:  Anyone with Google account
 Deploy ← آدرس URL را کپی کن و نگه دار (برای مرحله ۸).


مرحله ۶ — چک با diagnose
------------------------
 فهرست بالای ویرایشگر ← diagnose ← ▷ Run ← پایین Execution log را ببین:
   نسخه‌ی Code.gs = 1.12.2
   API_URL = همان آدرس مرحله ۳
   GOOGLE_CLIENT_ID = یک مقدار …apps.googleusercontent.com
   GET  → 200 · {"ok":false,"error":"وارد نشده‌اید"}
   POST → 200 · {"ok":false,"error":"وارد نشده‌اید"}

 اگر این‌طور نبود:
   - GET صفحه‌ی Sign in داد ← Who has access در مرحله ۳ روی Anyone نیست.
       Manage deployments ← Atlas Team ← ✏️ ← Anyone ← Deploy.
   - Sorry, unable to open / 404 ← API_URL آدرس قدیمی است ← مرحله ۴.
   - نسخه 1.12.2 نیست ← Code.gs ذخیره نشده ← مرحله ۱.

مرحله ۸ — تنظیمات داخل اطلس
---------------------------
 1. بک‌آفیس ← تنظیمات ← کارت Google:
      «رمز عبور تیم» ← رمز جدید ← ذخیره   (پیشنهاد: رمز اولیه را عوض کن)
      «لینک ورود با گوگل» = آدرس مرحله ۵ ← ذخیره
 2. بک‌آفیس ← افراد: ایمیل، سمت، تیم‌ها و سطح دسترسی هر نفر.
 3. بک‌آفیس ← تنظیمات: چرخه‌ی هفتگی (پنجشنبه) و قوانین تسک.
 4. اعلان‌ها داخل اطلس می‌آیند (زنگوله‌ی بالا). ایمیل‌ها همه پیش‌فرض خاموش‌اند؛ اگر ایمیلی خواستی:
    تنظیمات ← اتوماسیون‌ها ← همان مورد را روشن کن، و یک بار تابع installAutomations را Run کن.
 5. تنظیمات ← «سمت‌ها، تیم‌ها، واحدها و جلسه‌ها»: سمت هر نفر، تیم‌ها، واحدها (پروداکت، دیزاین، تک)
    و نام جلسه‌های هفتگی را خودت تعریف و عوض کن.
    کارها ← دکمه‌ی ⚙️ کنار «تسک جدید»: فیلدهای تسک، حوزه‌ها و ستون‌های کانبان.
 6. هر پروژه ← ویرایش ← «روز تحویل هفتگی» را انتخاب کن.

تازه‌های 1.12.2 — ورود با گوگل برای تیم
-------------------------------------
 چرا تیم «ورود با گوگل» نداشت: روی لینک Atlas Team، گوگل فقط به صاحب اسکریپت (مدیر برنامه) خودکار
 پیشنهاد می‌شود. بقیه‌ی اعضا فقط وقتی دکمه را می‌بینند که لینک انتشار «Atlas Google» در اپ ثبت شده باشد.
 1. Deploy ← Manage deployments ← Atlas Google ← Web app URL را کپی کن
    (اگر Atlas Google نداری: مرحله ۵ همین راهنما).
 2. اطلس ← بک‌آفیس ← تنظیمات ← «لینک ورود با گوگل (Atlas Google)» ← بچسبان ← ذخیره.
 3. صفحه‌ی ورود را برای یک عضو باز کن: زیر فرم رمز باید «ورود با حساب گوگل» باشد.
 • تا وقتی این لینک ثبت نشده، بالای اپ برای مدیر برنامه یک هشدار نارنجی نشان داده می‌شود.
 • اپ لینک اشتباه را نمی‌پذیرد: لینک /dev، لینک غیر Apps Script، یا همان لینک Atlas Team.
 • diagnose هم حالا می‌گوید این لینک ثبت شده یا نه.
 • یادت باشد: اگر انتشارها را از نو ساخته‌ای (مرحله ۰)، لینک Atlas Google عوض شده و باید دوباره ثبت شود.
