# ایجنت میزیتوی مدار

افزونه‌ی کروم با یک کار ساده: گفتگوی «دستیار میزیتو» را (از تاریخ شروع، پیش‌فرض ۱ تیر ۱۴۰۵) می‌خواند و هر تسکی که در پیام‌های آن آمده، به ترتیب تاریخ، در مدار ← میزیتو می‌نشاند: عنوان، توضیح، پروژه، سازنده، مسئولان، مهلت، چک‌لیست، انجام‌شدن، منشن‌ها و کامنت‌ها.

- فقط خواندن: در میزیتو چیزی نوشته نمی‌شود، پنجره‌ای باز نمی‌شود و روی چیزی کلیک نمی‌شود.
- لینک تسک برداشته نمی‌شود؛ خودتان در مدار روی هر مورد بگذارید.
- تسک‌هایی که تغییری نکرده‌اند دوباره فرستاده نمی‌شوند؛ «بازخوانی کامل» همه را دوباره می‌فرستد.

## نصب

1. در مدار: میزیتو ← ⚙ ← «ایجنت میزیتو» ← «کد اتصال» کنار نام خودتان ← کپی.
2. `chrome://extensions` ← Developer mode ← Load unpacked ← همین پوشه (نسخه‌ی قبلی را اول Remove کنید).
3. آیکون افزونه ← کد را بچسبانید ← «اتصال». یک تب میزیتو باز کنید (یک بار رفرش).

## دکمه‌ها

- **همگام‌سازی الان:** تسک‌های تازه و تغییرکرده.
- **بازخوانی کامل:** همه‌ی تسک‌ها دوباره (بعد از «پاک کردن داده‌های میزیتو» در مدار، این را بزنید).
- **تست سریع:** فقط پیام‌های یک هفته‌ی اخیر.
